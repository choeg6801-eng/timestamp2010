# 타임스탬프 2010 — 랜딩 페이지

"방과 후 5시, TV 앞과 MP3 이어폰으로 돌아가는 가장 완벽한 타임슬립."

학교 앞 문방구 콘셉트의 정적 사이트예요. 빌드 과정 없이 `index.html` 하나로 열립니다.

## 배포 후 채울 것
- `og:url` → 실제 사이트 주소
- `og:image` → SNS 공유용 대표 이미지 주소 (1200×630 권장)
- 파일에서 `[` 로 검색해 `[가격]`, `[출시일]`, `[사업자 정보]` 등 자리표시자 채우기
- 예약 폼을 실제 수집 도구(구글 폼, 스티비, Formspree 등)에 연결하기

## BGM
코드 안에서 Web Audio로 합성한 오리지널 곡이에요. 실제 음원으로 바꾸는 방법은 BGM 스크립트 상단 주석에 있어요.
